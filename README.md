# Barbearia Horizonte

Página institucional responsiva da Barbearia Horizonte, criada em HTML, CSS e JavaScript puro.

## Como executar

Abra o arquivo `index.html` diretamente no navegador. O projeto não exige instalação de dependências ou servidor de aplicação.

## Conteúdo

A página inclui apresentação da barbearia, serviços, seção de experiência, localização, horários e formulário de agendamento demonstrativo.

As imagens e fontes utilizadas são carregadas por URLs externas. O formulário apenas exibe uma confirmação no navegador e não envia dados para um servidor.

## Publicação

O arquivo `index.html` pode ser publicado gratuitamente por meio do GitHub Pages, Netlify, Vercel ou qualquer serviço de hospedagem estática.

## Observação

Os preços, endereço e informações de contato são demonstrativos, conforme indicado no site original.
